# Task 1 — Golang Concurrency (Goroutine, Channel, WaitGroup)

This project demonstrates basic concurrency in Golang.

It processes a list of numbers in parallel using Goroutines and sends results through a channel.

## 🛠 Tech Stack

- Go (Golang)
- Goroutine
- Channel
- sync.WaitGroup

## ⚙️ How to Run

```bash
go run main.go
