This is the second backend assignment from Sinau Koding Bootcamp Batch 5.

It is a user REST API built with:

Golang

Echo Framework

echo-swagger

Validator (go-playground)

API Endpoints

GET /users

GET /users/{id}

POST /users

PUT /users/{id}

DELETE /users/{id}

⚙️ How to Run
go run main.go


The API runs on:

http://localhost:8080


Swagger docs:

http://localhost:8080/swagger/index.html
